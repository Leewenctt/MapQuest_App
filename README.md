# MapQuest App

Made in compliance with DEVASC Lab 4.9.2.

## How to Run

Clone the repository

   ```bash
   git clone https://github.com/Leewenctt/MapQuest_App
   ```

Navigate to the project directory

   ```bash
   cd MapQuest_App
   ```

Run the Python script

   ```bash
   python MapQuest_App.py
   ```
